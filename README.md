# Paradise Nursery Shopping Application

A dynamic e-commerce web application built with React and Redux Toolkit for an online plant shop called Paradise Nursery. 

## Features
- **Landing Page:** Engaging welcome page with the company name and a "Get Started" button.
- **Product Catalog:** Houseplants grouped into at least three unique categories, with thumbnails, names, descriptions, and prices.
- **Shopping Cart Management:** Add plants to the cart, disable buttons for added items, dynamically update cart quantities, and calculate total costs.
- **Redux State Management:** Uses Redux slices to handle cart state globally across components.
- **Navigation:** Responsive navigation bar linking to Home, Plants, and Cart pages with a dynamic item counter.

## Tech Stack
- React
- Redux Toolkit
- JavaScript (ES6+)
- HTML5 / CSS3
